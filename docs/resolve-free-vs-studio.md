# DaVinci Resolve Free vs Studio

*[Version française](resolve-free-vs-studio.fr.md)*

mlv2Resolve works with both editions of DaVinci Resolve. The difference is mostly **how** Resolve is driven, plus
one resolution limit. This page lists what is identical, what changes, and what you do by hand with the free edition.

## Why there is a difference

mlv2Resolve talks to Resolve through Resolve's Lua scripting API. Blackmagic only allows **external** scripting
(a program outside Resolve, here `fuscript`, connecting to the running Resolve) in **Studio**. The free edition
still runs scripts launched **from inside Resolve** via **Workspace → Scripts**.

So mlv2Resolve does the same work in both cases, but:

- **Studio:** the app runs the script itself. One click in mlv2Resolve is enough.
- **Free:** the app writes the script into Resolve's script folder
  (`~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility`), and you start it
  from Resolve's menu.

## Works the same in both editions

These features happen in mlv2Resolve or on disk, so the Resolve edition does not matter:

| Feature | Notes |
| --- | --- |
| Mounting MLV as virtual CinemaDNG (FUSE-T) | Footage appears in `~/MLV Mounts/<shoot>`. |
| Matching WAV audio | Served next to each DNG sequence. |
| Dual ISO modes (Smooth Editing / Grading Quality) | Switched live by the engine; use **Refresh** in Resolve. |
| SenseFlow A1 gyro sync and `.gyroflow` files | Generated by the app. |
| Desqueezed thumbnails and previews | Shown in the app. |
| **Open Resolve** | Only launches Resolve. |

These features are done by the project script. **Free runs the same script**, so you get the same result once you have
started it from the Workspace menu:

| Feature | Notes |
| --- | --- |
| Create one named project from all mounted shoots | Same script in both editions. |
| Import the CinemaDNG sequences and WAV files, then sync audio by timecode | |
| Project frame rate (automatic or manual) | |
| Color management (DWG / Intermediate, color group **All**, pre-clip and post-clip CSTs, Kodak 2383 option) | Built from standard nodes, CSTs and LUTs. |
| **All shots** timeline, or an empty timeline with the group grades | |
| Gyroflow(NiYien) node on each clip | mlv2Resolve does not check the Resolve edition here. The OFX plugin must be installed, and it must accept your Resolve edition. |
| Add new clips to a linked project, **Open Project** | |
| Anamorphic desqueeze of timeline clips | Done with the clip's Input Sizing preset or a zoom on the timeline item. See the timeline size limits below. |

## What changes with the free edition

### 1. You start each action from Resolve

The workflow is the same for every action (**Create Project**, **Open Project**, adding new clips):

1. Wait for gyro sync to finish if you use a SenseFlow A1.
2. Open Resolve (the **Open Resolve** button works).
3. In mlv2Resolve, click the action you want. With the free edition, the app cannot connect and shows the step-by-step
   guide. It has already written the script for that action.
4. In Resolve, run **Workspace → Scripts → mlv2Resolve**. The script does what you chose in step 3.

If you start the script before choosing an action, it prints *“Choose an action in mlv2Resolve first.”*

**Desqueeze in Resolve** has its own script, **Workspace → Scripts → mlv2Resolve Desqueeze**. mlv2Resolve keeps it
up to date whenever you mount or unmount a shoot, so you don't need to click anything in the app first. Run it with
the project open.

### 2. Timeline size is limited to UHD

Resolve Free cannot use a timeline larger than **3840×2160**. With **Project size: Automatic**, Studio uses the native
desqueezed size of the footage. For example, a 1x3 4.8K shoot gives 4800×2008. The free edition caps the project at
**3840×2160**, and the full image is fitted inside it with bars where needed.

**UHD** and **HD** settings work the same in both editions.

### 3. Fitting anamorphic shots of a different aspect ratio

With Studio, a clip whose desqueezed aspect differs from the timeline gets a special preset,
**`mlv2Resolve 1x<N> Fit …`**. That preset already includes the scale-down, so the whole image is visible in the
Media Pool and in any timeline.

With the free edition, the script uses the plain **`mlv2Resolve 1x<N>`** preset. On the timelines it creates, it sets
the clip's **Zoom X / Zoom Y** to fit the image. The result is the same on those timelines. If you drag the same clips
onto a new timeline yourself, you may need to adjust the zoom or **Input Sizing** again.

### 4. Manual fallback for desqueeze

If no script can run, set the desqueeze by hand. Use the factor mlv2Resolve shows for the shoot:

> **Color page → Sizing → Input Sizing → Width = N** (for example 3 for 1x3)

The app shows this hint the first time you mount an anamorphic shoot.

## What Studio needs

Studio does everything directly from mlv2Resolve, but you must allow external scripting once:

> **DaVinci Resolve → Preferences → System → General → External scripting using: Local**

Then:

- Resolve must be running, and **Desqueeze in Resolve** needs a project open.
- **Create Project** and **Open Project** work from the app, and so does adding new clips to a linked project.
- If Resolve does not answer, mlv2Resolve reminds you of this setting. In the meantime you can still use the
  Workspace script method above. It also works in Studio.

## Summary

| | Resolve Free | Resolve Studio |
| --- | --- | --- |
| Mount, Dual ISO, gyro sync, previews | ✅ | ✅ |
| Start actions | Click in the app, then **Workspace → Scripts → mlv2Resolve** | One click in the app |
| Project creation, audio sync, color management, All shots timeline | ✅ (via the script) | ✅ |
| Gyroflow(NiYien) node | ✅ if the plugin is installed and supports your edition | ✅ if the plugin is installed |
| Automatic project size above UHD | ❌ capped to 3840×2160 | ✅ native desqueezed size |
| Anamorphic Fit presets for other aspect ratios | ❌ (timeline zoom instead) | ✅ |
| Desqueeze in Resolve | **Workspace → Scripts → mlv2Resolve Desqueeze** | One click in the app |
| One-time setup | None | **External scripting using: Local** |

> Real tests were run with Resolve **Studio** 21.1.1. The free edition uses the same script, plus the branches
> described above, but a full visual check in Resolve Free has not been documented yet.
