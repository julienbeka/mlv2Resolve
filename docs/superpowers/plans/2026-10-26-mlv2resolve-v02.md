# mlv2Resolve v0.2 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver the approved mlv2Resolve rename, four-section Tahoe window, gyro previews and separate Resolve project actions.
**Architecture:** Keep SwiftUI/AppKit and the observable AppState. Extend the Lua boundary with explicit create/open operations and stable source/project associations; persist timeline preferences in the existing defaults domain. Decode mounted previews asynchronously and keep their lifetime bounded to mounted clips.
**Tech Stack:** Swift 6, SwiftUI/AppKit, XCTest, Resolve Lua, Xcode 26.
**Spec:** docs/superpowers/specs/2026-10-26-mlv2resolve-design.md

## Global Constraints
- macOS 14 minimum, macOS 26 native glass where available.
- Public name mlv2Resolve, next release v0.2; preserve net.mlv2dng.app identity and existing data.
- Open project never creates or changes timeline/media; clearing cache removes associations only.
- No overwriting existing projects, profiles or foreign Gyroflow files.
- All user-facing additions in English and French.

## Review Focus
- Duplicate shoot names on different disks must remain distinct through source identities.
- Missing project / changed Resolve library must not silently create a replacement.
- Partially failed creation must not cache an unsaved project association.
- Mixed aspect ratios and anamorphic clips must fit HD/UHD entirely.
- Unmounted disks and unavailable previews must leave a responsive interface.
